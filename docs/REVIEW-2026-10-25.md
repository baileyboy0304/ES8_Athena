## Observations that do not justify speculative fixes

The report's one initial voice test failure is not enough to establish a cause.
The satellite already reports unavailable until both connections are up. The guide
explains waiting for availability before retrying. The observed music-volume change
also has no established cause; no volume behaviour was changed for it.

The walkthrough did not test signed-in streaming playback, the physical mute
button or the new double-tap behaviour. Its passing results describe the previous
build after workarounds, not a clean validation of this redesigned setup flow.

## Upgrade constraint

The previous bundled APK's signing certificate is unavailable on this Linux host.
The new APK uses the existing Linux debug signing key. A fresh install works;
Android blocks an in-place update of the older certificate. No working app was
uninstalled, and no credentials or signing keys are published. Keep the signing
key backed up privately for future compatible updates.
